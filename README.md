A short poem about agency — the power to ask and to be given — written for the
[$50 bounty on make.fun](https://make.fun/bounty/the-poem-about-permission-20261121-0235).

`main.ts` (Node 22, stdlib only, no network, no randomness) writes the poem to
`/output/entry.txt`. The poem is 1–280 characters, deterministic: the same bytes
on every run.

Run it:

```sh
node main.ts
cat /output/entry.txt
```
